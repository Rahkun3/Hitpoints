# hitpoints-cms

Self-hosted wiki CMS for hitpoints.eu (Unraid + nginx).

**Active development is on `dev`.** `main` is the release line. Do not merge `dev` into `main` without explicit consent.

To run or deploy, check out `dev`:

```
git clone https://github.com/Rahkun3/hitpoints-cms.git
cd hitpoints-cms
git checkout dev
```
